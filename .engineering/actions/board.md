# Action: board
Intent/scope: Audit the Kanban board against workflow/kanban-board.md with the deterministic script (integrations/kanban/audit_board.py): Status validity and transitions, derived fields (Etapa, Precisa de você, Gates), the human summary, Definition of Ready before work, owner and staffing during work, evidence before review, gates on one snapshot and Definition of Done before completion, human acceptance, stale cards and work in progress. Without arguments audit the whole configured project; with a card reference audit that card before a transition.
Responsible specialist: scrum-master; principal routes each finding to its owner and applies or authorizes mechanical corrections.
Input: project owner and number (or a board export file), the transition about to be made if any, project profiles and existing authorizations for board write.
Output: findings grouped by responsible party with the script's rule IDs, the list of mechanical corrections, one summary line (cards checked, errors, warnings, stale, waiting on the human) and what blocks the pending transition. The specialist never fills content, never ticks a checklist and never moves a card to hide an error. Common policies and workflow apply to standalone invocations too.
